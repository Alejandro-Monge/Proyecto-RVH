# docs — technical documentation

Technical documentation of the project, organized by module in `modules/`. Each
file describes the final state of a pipeline module: perception and
detection, tracking and reconnection, position and route, lane map and SUMO
staging, zones and occupancy, causality contract, matching against the ground
truth, and the payload contract and the layers of the 3D web viewer.

They are self-contained reference documents; they complement the README of each
package of the repo. Other module or contract README live next to the code or
the data they document (for example in `reconstruccion_causal/docs/` and in
`data/ground_truth/`).
